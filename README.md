# Wishlist v3

Эта версия исправляет две проблемы предыдущей версии:

1. Старые карточки теперь автоматически отправляются в `/api/product` при загрузке страницы — раньше API использовался только при добавлении нового товара.
2. Убраны случайные/заглушечные изображения. Если настоящее фото не получено, показывается «Фото не получено».
3. API сначала использует Microlink (сервис с браузерным чтением страниц), затем пробует прямой запрос.
4. Ссылка «Перейти к товару» принудительно открывает исходный URL в новой вкладке.
5. Добавлена кнопка «Обновить данные» для повторной загрузки всех товаров.

## Важно

Microlink имеет бесплатный лимит, поэтому это подходит для небольшого личного вишлиста. Для большого количества запросов понадобится API key/платный тариф. Магазины также могут блокировать автоматический доступ даже через браузерный сервис.

## Деплой

Загрузить все файлы в GitHub и подключить репозиторий к Vercel.

После загрузки новой версии обязательно сделай новый Commit. Vercel автоматически создаст новый deployment.

## После обновления

В браузере может остаться старая версия и старый localStorage. Сделай Ctrl+F5.

Если карточки всё ещё старые:
DevTools -> Application -> Local Storage -> домен сайта -> удали `arinaWishlistV2` (новая версия хранит данные в `arinaWishlistV3`).

Нажми «Обновить данные».


## Ручное добавление Ozon / Wildberries

В интерфейсе есть вкладка **«Вручную»**. Она не обращается к магазину вообще.

Нужно указать:
- ссылку на товар;
- магазин;
- название;
- URL фотографии (необязательно);
- описание (необязательно).

Для фотографии Ozon/Wildberries: открой изображение товара, нажми правой кнопкой мыши и выбери **«Копировать адрес изображения»**, затем вставь URL в поле «Фото товара».

Это позволяет добавлять товары даже тогда, когда магазин блокирует автоматическое чтение.

\n## Новое: бронирование подарков

У каждого товара появилась кнопка «Отметить забронированным». Состояние сохраняется в `localStorage`, поэтому после перезагрузки страницы отметки не пропадают. Отметку можно поставить прямо на карточке или внутри окна товара.

Также исправлена ошибка в автоматическом добавлении: код больше не обращается к несуществующим полям `titleInput`, `imageInput` и `descInput`.
