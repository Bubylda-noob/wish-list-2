# 💜 Мой вишлист — версия с автоматическим импортом товаров

Эта версия переделана так, чтобы при вставке ссылки сайт **сам пытался получить**:

- название товара;
- главное фото;
- описание;
- исходную ссылку на товар.

Поддерживаемые магазины: **Ozon, Wildberries, Детский мир и OZ**.

## Важное отличие от старой версии

GitHub Pages умеет только статические файлы и не может выполнять серверный код. Поэтому автоматическое чтение страниц магазинов вынесено в серверless API `api/product.js`.

Самый простой вариант: разместить этот же проект на **Vercel**. GitHub при этом можно использовать как хранилище кода: ты загружаешь ZIP-файлы в репозиторий, а Vercel автоматически разворачивает сайт.

### Как опубликовать

1. Создай новый GitHub-репозиторий.
2. Распакуй этот ZIP.
3. Загрузи в репозиторий:
   - `index.html`
   - `style.css`
   - `script.js`
   - `package.json`
   - `vercel.json`
   - папку `api` вместе с `api/product.js`
4. Подключи репозиторий к Vercel.
5. В Vercel выбери обычный deploy без отдельной сборки.
6. После публикации сайт и `/api/product` будут работать на одном домене.

## Как работает добавление

Пользователь вставляет:

`https://...ссылка-на-товар...`

Нажимает **«Добавить в вишлист»**.

Frontend отправляет ссылку в `/api/product`, а сервер пытается прочитать Open Graph / JSON-LD данные страницы.

Если магазин разрешает такой запрос, карточка получает настоящие данные.

Если магазин включает антибот-защиту и не отдаёт HTML, сайт **не подставляет случайную фотографию**, а показывает понятную ошибку.

## Ограничение, которое важно понимать

Ни один универсальный скрипт не может гарантировать получение данных со всех страниц Ozon/Wildberries: магазины могут менять разметку, требовать JavaScript, CAPTCHA, авторизацию или блокировать серверные запросы.

То есть схема теперь правильная технически, но конкретный магазин всё равно может иногда не разрешить автоматическое чтение.

## Сохранение товаров

Товары по-прежнему сохраняются в `localStorage` браузера.

Это означает:

- товары сохраняются после обновления страницы;
- список доступен в том же браузере;
- но это **не общая база для всех посетителей**.

Для настоящего общего вишлиста понадобится база данных (например, Supabase/Firebase) и авторизация/правила доступа.

## Локальный запуск

Можно открыть `index.html`, но автоматический `/api/product` при таком запуске работать не будет, потому что serverless API требует серверной среды.

Для проверки всей функции лучше запускать проект через Vercel или локальный Vercel CLI.
